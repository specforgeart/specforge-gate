# Support

SpecForge Gate is pre-release open-source software. There is no commercial support offering and no promised response time.

## Bug reports

Use GitHub Issues for reproducible bugs. Include:

- the command you ran;
- the input file or a minimal redacted example;
- expected behavior;
- actual behavior;
- operating system and Python version.

## Feature requests

Use GitHub Issues for feature requests. Describe the problem, proposed scope, out-of-scope items, and observable acceptance criteria.

## Usage questions

Use GitHub Issues for usage questions about the CLI, configuration, suppression directives, examples, or documentation. Keep questions focused and include the command or document section involved.

## Security reports

Do not post exploit details publicly. Follow [SECURITY.md](SECURITY.md) for responsible reporting.
