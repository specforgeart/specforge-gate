# Сохранённый фильтр поиска

## Цель
Повторно использовать выбранные параметры поиска.

## Результат
Выбранные значения отображаются в форме поиска.

## Объём
- Добавить фильтр и сохранить выбор.

## Не входит
- Общие фильтры для разных пользователей.

## Критерии приёмки
- Когда выбран фильтр с 3 полями, тогда форма содержит эти 3 значения.

## Ошибки
- Удалённый фильтр возвращает сообщение об отсутствии.
