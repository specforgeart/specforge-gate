# Импорт клиентов из CSV

## Цель
Загрузить записи клиентов из файла CSV.

## Результат
Допустимые строки становятся записями клиентов.

## Не входит
- Формат XLSX.

## Критерии приёмки
- Когда файл содержит 10 допустимых строк, тогда создаются 10 записей.
- Когда строка содержит неизвестное поле, тогда строка отклоняется.
