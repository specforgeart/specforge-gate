# Импорт клиентов из CSV

## Цель
Загрузить записи клиентов из файла CSV в UTF-8.

## Результат
Допустимые строки становятся записями, а отклонённые строки попадают в отчёт.

## Не входит
- XLSX.
- Формулы таблиц.
- Запуск по расписанию.

## Критерии приёмки
- Когда файл содержит 100 допустимых строк, тогда появляются 100 записей.
- Когда отклонены 3 строки, тогда отчёт содержит 3 номера строк.
- Для файла до 10 МБ обработка занимает не более 2 минут.

## Ошибки
- Недопустимая кодировка возвращает ошибку кодировки.
- Повторяющиеся идентификаторы отклоняются.
- Ошибка базы данных не оставляет частичную пачку.
