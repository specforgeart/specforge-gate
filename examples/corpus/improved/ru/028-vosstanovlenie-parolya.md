# Восстановление пароля

## Цель
Вернуть владельцу учётной записи доступ после утраты пароля.

## Результат
Одноразовая ссылка принимает новый пароль для связанной учётной записи.

## Не входит
- Восстановление без доступа к зарегистрированной почте.
- Смена пароля администратором.

## Критерии приёмки
- Когда действующая ссылка получает пароль из 12 символов, тогда хеш пароля меняется 1 раз.
- Когда срок ссылки истёк, тогда запрос отклоняется.
- Когда использованная ссылка отправлена повторно, тогда запрос отклоняется.

## Ошибки
- Ошибка доставки письма фиксирует состояние для повторной попытки.
- Ошибка поиска токена не меняет пароль.
