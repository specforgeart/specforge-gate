# Экспорт отчёта

## Цель
Дать оператору выгрузку текущего результата проверки для автономного просмотра.

## Результат
Файл Markdown в UTF-8 содержит итоговый статус и все замечания.

## Не входит
- PDF.
- Отправка по почте.
- Архив прошлых отчётов.

## Критерии приёмки
- Когда отчёт содержит 3 замечания, тогда файл содержит все 3 замечания.
- Когда исходный текст содержит кириллицу, тогда файл сохраняет UTF-8.
- Для отчёта до 1 МБ выгрузка занимает не более 2 секунд.

## Ошибки
- Недоступный каталог не оставляет частичный файл.
- Пустой отчёт содержит статус PASS и 0 замечаний.
