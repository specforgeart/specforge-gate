# Сохранённые фильтры поиска

## Цель
Повторно использовать именованный набор условий поиска.

## Результат
Выбор фильтра восстанавливает значения полей формы поиска.

## Не входит
- Общие фильтры для разных учётных записей.
- Автоматические рекомендации.

## Критерии приёмки
- Когда фильтр содержит 3 поля, тогда форма содержит те же 3 значения.
- Когда имя фильтра изменено, тогда список содержит новое имя 1 раз.
- Когда фильтров нет, тогда список показывает пустое состояние.

## Ошибки
- Удалённый фильтр возвращает сообщение об отсутствии.
- Недопустимое значение поля игнорируется и фиксируется.
