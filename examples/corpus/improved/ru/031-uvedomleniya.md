# Настройки уведомлений

## Цель
Выбирать события учётной записи, для которых нужны письма.

## Результат
Каждый поддерживаемый тип события следует сохранённому состоянию включения.

## Не входит
- SMS.
- Рекламные рассылки.
- Редактирование шаблонов.

## Критерии приёмки
- Когда письма отключены, тогда событие ставит в очередь 0 писем.
- Когда письма включены, тогда событие ставит в очередь 1 письмо.
- Когда сохранены 2 типа событий, тогда после перезагрузки остаются 2 значения.

## Ошибки
- Недопустимый адрес фиксирует ошибку доставки.
- Ошибка записи сохраняет прежние значения.
