# Архив задачи

## Задача
Получить архив завершённой задачи для внутреннего хранения.

## Что должно получиться
ZIP содержит описание задачи и 2 файла результата.

## Вне скоупа
- Комментарии пользователей.
- Удалённые файлы.

## Критерии приемки
- Когда задача содержит 2 файла, тогда ZIP содержит 2 файла результата.
- Для архива до 100 МБ формирование занимает не более 2 минут.

## Негативные сценарии
- Отсутствующий файл возвращает ошибку и не оставляет частичный архив.
