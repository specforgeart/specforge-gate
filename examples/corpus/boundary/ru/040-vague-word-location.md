# Сводка проекта

## Цель
Дать руководителю сводку по активному проекту.

## Результат
Сводка формируется оперативно для выбранного проекта.

## Не входит
- Архив завершённых проектов.

## Критерии приёмки
- Когда проект содержит 5 задач, тогда сводка содержит 5 строк задач.

## Ошибки
- Недоступное хранилище возвращает сообщение о недоступности.
